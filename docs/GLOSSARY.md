# pj1 Domain Glossary (SafeTix / Event Platform)

This glossary defines the canonical domain terms used across `apps/api` and `apps/web`.

- **Event**: Top-level scheduled occasion created by an Organiser (`events` table, `apps/api/src/routes/events.routes.ts`). Has a `seating_mode` (`RESERVED` or `GA`), cancellation deadline, refund percentage, and per-user ticket limit.
- **Session**: A specific date/time occurrence of an Event (`sessions` table), owning its own `ticket_types` and (for `RESERVED` events) `event_seats`.
- **SeatingMode**: Either `RESERVED` (seat-level grid selection via `event_seats`) or `GA` (General Admission capacity-based allocation on `ticket_types`).
- **TicketType**: A pricing and capacity tier within a Session (e.g., `VIP Front Row`, `Standard Orchestra`, `Balcony Tier`).
- **Seat**: A physical seat in a `RESERVED` Session (`event_seats` table) with `section`, `row_label`, `seat_number`, coordinates `(x, y)`, `status` (`AVAILABLE`, `HELD`, `BOOKED`), and optimistic `version`.
- **Hold**: A temporary time-bounded reservation (`holds` table, default `DEFAULT_HOLD_MINUTES = 10`) that locks selected seats or GA capacity before payment confirmation.
- **BookingStrategy**: Seat-locking concurrency mode configured via `BOOKING_STRATEGY` (`pessimistic`, `conditional`, or `naive`) in `apps/api/src/services/hold-strategies.service.ts`.
- **Booking**: A confirmed or cancelled reservation (`bookings` table, `apps/api/src/services/bookings.service.ts`) with a unique `reference`, `total_amount`, and issued Tickets.
- **Ticket**: An individual admission pass (`tickets` table) belonging to a Booking, containing an HMAC-signed static QR code (`signTicketCode`) and optional seat assignment.
- **RollingPass (SafeTix™)**: Short-lived (15-second window) cryptographic QR token (`ROLL.<encodedId>.<window>.<sig>`) generated by `generateRollingPassCode` in `apps/api/src/services/qr.ts` to prevent screenshot scalping.
- **Waitlist**: Queue of users waiting for released seats or capacity on a sold-out Session (`apps/api/src/routes/waitlist.routes.ts`).
- **CheckIn**: Gate validation of a static or rolling ticket pass (`apps/api/src/routes/checkin.routes.ts`) by `STAFF`/`ADMIN` users, recording `checked_in_at`.
- **Organiser**: An account (`ORGANISER` role) and organization profile (`organisers` table) permitted to create events, build seat maps, and view attendance reports (`apps/api/src/routes/reports.routes.ts`).
